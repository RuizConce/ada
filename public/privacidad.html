ADA · Política de privacidad

Última actualización: 23 de octubre de 2026

ADA es una asistente personal de uso privado, creada y operada por Cristian Ruiz (Iquique, Chile) para su propio uso. No es un servicio abierto al público.

Qué datos usa

  • Lo que el usuario le dice o escribe a ADA: notas, decisiones, compromisos, encargos, contactos y conversaciones.
  • Si el usuario conecta su cuenta de Google: los eventos de su Google Calendar y los archivos de su Google Drive (incluidos Docs y Sheets), solo para consultarlos, ordenarlos o editarlos cuando el usuario lo pide.
  • Si el usuario lo autoriza: los correos de su Gmail, para buscarlos, leerlos, resumirlos, archivarlos y preparar respuestas. Un correo solo se envía cuando el usuario toca el botón de enviar.
  • Si el usuario lo autoriza: sus contactos de Google (nombre, correo, teléfono y organización), solo para encontrar a la persona a la que quiere escribirle. No se comparten con nadie.

Para qué se usan

Exclusivamente para que ADA funcione como asistente del propio usuario: responder, organizar su agenda, sus archivos y su correo, y preparar documentos. Los cambios en el calendario, en Drive o en Gmail solo se realizan con la confirmación explícita del usuario.

Dónde se guardan y con quién se comparten

  • Los datos se almacenan en un servidor y una base de datos privados en Railway.
  • Para generar respuestas, el contenido de cada conversación se envía a la API de Claude (Anthropic). Para la voz, el texto de las respuestas se envía a Google Cloud Text-to-Speech.
  • No se venden ni se comparten datos con terceros para publicidad ni con ningún otro fin.
  • El uso de información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso a Google se puede revocar en cualquier momento desde Ajustes en ADA (Desconectar) o desde myaccount.google.com/permissions. Al desconectar, ADA elimina los tokens de acceso guardados.
